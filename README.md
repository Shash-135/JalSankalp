Ground-level pump operators use a dedicated mobile application to log pump states, manage offline field data, and sync with the central server.

1. Go to the **[Releases](../../releases)** tab on this GitHub repository.
2. Download the `JalSankalp-Operator-App.apk` file directly to your Android smartphone.
3. Open the downloaded `.apk` file to install it. 
4. *Note: Your phone may prompt you to "Allow installation from unknown sources". Please enable this in your settings to proceed.*
